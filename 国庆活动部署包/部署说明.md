## 二、前置条件（基础设施不随包，远端需已具备）

- BDS **1.26.51** + LeviLamina **26.51.x**
- **legacy-script-engine-quickjs**（本包两个插件 manifest 均声明 `lse-quickjs`，**不是 NodeJS**；
  测试服上的 nodejs 引擎只是给 LuckyClover-Panel 用的，本包不含 Panel，无需安装）
- 该引擎模组自身依赖：**LegacyMoney + LegacyRemoteCall + iListenAttentively**（缺一个引擎都起不来）
- **LegacyMoney** 同时是 Wave 的全局 `money` 接口——缺它活动能跑，但商店/修理/复活币/击杀奖励**全部失效**
- 不在包内（与活动无关）：HologramLib、`/shapetest` 探针、玩家描边 RP（客户端个人资源包）

## 三、部署步骤

1. **停远端服**
2. 解压本包，把三个目录分别**合并**到远端服务器根目录的对应位置（见上表）
3. 行为包本体必须真的放在 `behavior_packs/` 下才会加载；世界侧的接线文件若缺失按上表注释补
4. 远端 `server.properties` 设置（世界需已单独部署）：
   ```properties
   level-name=Colosseum-travertine-v4
   ```
   ⚠ **活动坐标绑定斗兽场世界**（核心 97.5,-49,127.5 / 集合点 96,-49,116 / 观战席等全部
   是该世界内绝对坐标），玩家必须身处这个世界活动才对得上。与测试服做法一致：
   活动期间这个实例就以斗兽场为主世界。若远端现有主世界是别的，不要直接并入——
   要么用独立实例跑活动，要么活动结束后把 `level-name` 换回去。
5. 启动服务器

## 四、启动验证清单

**启动日志应出现（且无 `couldn't resolve the symbol`）：**

```
正在启用 LuckyClover-Sidebar v1.1.0
正在启用 LuckyClover-Wave v1.2.2
LuckyClover-Sidebar loaded ...
LuckyClover-Wave loaded (国庆尸潮守点, /wave)
```

**首次进服 deop（地图全员 OP 问题的兜底）：**

```
first join deop: Steve (xuid=...)     ← 该玩家首进被自动 deop ✓
first join, keep op (auto_deop.keep_op): Mell   ← 豁免名单生效
```

**游戏内单人冒烟：**

1. `/wave status` —— 显示布场信息（config 自带全部坐标）
2. `/wave start 1` —— 跑一轮，对照日志关键词：
   ```
   inventory stashed: xxx (N items) cleared=true    ← 赛前暂存+清空 ✓
   Gave Iron Sword * 1 to ...                        ← kit 在暂存之后发 ✓
   （死两次）还在死亡界面(health=0)，等真正重生后再落点
   eliminate 落点就位: xxx → (观战席坐标)             ← 观战席落点自愈链 ✓
   inventory restored=1 offline_kept=0               ← 结束赛前物品返还 ✓
   ```
3. 结束时：家当回来、活动装备消失、被淘汰者恢复生存模式

**若日志出现 `inventory clear INEFFECTIVE` / `落点自检超时` / `restore slot N failed`**——
每一步失败现在都会自己招供，把那段日志发回来即可定位。

## 五、config.json 备注（已随包，调优版 2026-09-28）

- 斗兽场坐标、观战席、活动商店（8 商品）、精英词缀、波间三选一、Boss 定时/狂暴、
  波次成长、锁夜、击杀奖励——全部已配好，开箱即用
- 改过地形/重建场地 → 站定后重设：`/wave setcore` `/wave setlobby` `/wave setseat`
  `/wave setreturn` `/wave addspawn`（自动写回 config）
- 想要"活动服式真清空"（结束不返还赛前物品）→ `inventory.restore_after: false`
- 进场装备 = `kit_commands`；死亡上限 = `deaths_limit`（默认 2）；结算奖命令 = `rewards`
- **首次进服自动 deop**：`auto_deop.enabled`（默认开）；`auto_deop.keep_op` = 豁免名单
  （游戏名/xuid）——**管理必须把自己加进去**（`"keep_op": ["你的游戏名"]`），否则你下次
  进服也会被 deop 一次（重新 op 需走控制台）
- 新配置键（auto_start / auto_deop / health_per_player）：
  本包 config 已补全；**远端旧 config 不用手改——启动一次服务器，插件会自动把合并后的
  完整配置写回 config.json**（已保存的调优值优先，不会被默认值覆盖），之后直接编辑即可

## 六、升级/回滚

- 单独升级插件 = 只覆盖 `plugins/LuckyClover-Wave/`（**保留远端 config.json**，别用包里的覆盖回去）
- 回滚 = 停服，删掉 `plugins/LuckyClover-Wave`、`plugins/LuckyClover-Sidebar`、
  `behavior_packs/LuckyClover-Wave-AI`，恢复原 server.properties
